### Full Description

Join us for a hands-on lab where you'll go from a GitHub repo to a live, cloud-deployed API in under 45 minutes — using IBM Bob, IBM's AI coding assistant, to do the heavy lifting.

The application is real: an IT support ticket classifier that reads a plain-English problem description, determines the issue type, assigns a priority, routes it to the right team, and returns a structured response with a ticket ID and SLA — all in under one second. It's a working proof-of-concept you can take to a client conversation the same day.

The session runs two parallel tracks — one for first-time Bob and AI coding assistant users, one for those who've seen it before and are ready to go straight to building and deploying. Both use the same codebase; Track B simply goes further, ending with a live public URL on IBM Cloud.
